# 2026 천안시 아동정책 웹 프레젠테이션

첨부된 10장 PowerPoint를 시각적으로 보존하여 정적 HTML 웹 프레젠테이션으로 구성했습니다.

## 실행
`index.html` 파일을 브라우저로 열거나 폴더 전체를 GitHub 저장소에 업로드하고 Settings → Pages → Deploy from a branch → main / (root)를 선택하세요.

## 조작
- 상단 메뉴: 해당 슬라이드 이동
- 이전/다음 버튼 또는 키보드 좌/우, PageUp/PageDown, Home/End
- 모바일: 좌우 스와이프
- 슬라이드 위에서 마우스 휠 스크롤
- `G`: 전체 슬라이드 썸네일, `F`: 전체화면
- URL 끝 `#slide-3`처럼 특정 슬라이드 직접 연결

## 구성
- `index.html`: HTML/CSS/JS 일체형
- `assets/slide-01.jpg` ~ `slide-10.jpg`: 원본 PPT에서 변환한 슬라이드 이미지

## 참고
원본 슬라이드 내용을 그대로 보여주기 위해 각 슬라이드를 이미지로 렌더링했습니다. 따라서 이미지 속 텍스트/차트는 개별 HTML 요소로 편집되지 않습니다. 별도의 서버·DB·CDN은 필요하지 않습니다.
원본 7번 슬라이드의 홍보영상 언급은 슬라이드의 문구이며, 첨부 PPT 내 별도의 동영상 파일이 확인되지 않아 자동 재생 영상은 포함하지 않았습니다.
